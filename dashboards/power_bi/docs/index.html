Download your PBIP (.zip)

Enter your project.dataset.table above and click Download pre-configured PBIP (.zip). Unzip the archive to get BQAA_Agent_Analytics.pbip, BQAA_Agent_Analytics.SemanticModel/, and BQAA_Agent_Analytics.Report/.

02

Open in Power BI Desktop or Fabric

In Power BI Desktop (with PBIP / TMDL / PBIR preview features enabled), open BQAA_Agent_Analytics.pbip. Or deploy directly to a Power BI Service / Microsoft Fabric workspace using deploy_fabric.py below.

03

Sign in with Google OAuth2 & Refresh

When prompted for Google BigQuery credentials, choose OAuth2 (Organizational privacy level), sign in with a Google account that has bigquery.dataViewer and bigquery.jobUser, and click Refresh.

Prefer the command line?

Generate the same pre-configured .zip archive from a git checkout or deploy directly to a Fabric / Power BI Service workspace:

python dashboards/power_bi/tools/generate_pbip.py --output-zip BQAA_Agent_Analytics.zip --project test-project-0728-467323 --dataset bqaa_fixture_adk_1_27_0 --table agent_events
python dashboards/power_bi/tools/deploy_fabric.py --workspace-id <WORKSPACE_GUID> --token-file /path/to/fabric.token --project-dir ./BQAA_Agent_Analytics --display-name "BQAA Agent Analytics"
