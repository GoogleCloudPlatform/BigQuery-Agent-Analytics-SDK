# SYNTHETIC — hashing regression only

`bqaa-germany.json` is a hand-written, **synthetic** BQAA-shaped trace from
the github.io prototype. Nothing in it was written to a live table. It is
kept only so `compute_identities` can be pinned against the JS
`identities.json` triple. It is never the demo and never the default adapter
input; see `../live_observe_agent_events.json` for the live run.
